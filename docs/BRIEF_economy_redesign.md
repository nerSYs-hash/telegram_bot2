## 1. Что есть сейчас (карта экранов)

Раздел «Экономика» — это **одна страница** (`EconomyPage`) + 4 модалки/панели.

### 1.1 Главная страница
Файл: `Admin_SITE/components/economy/EconomyPage.jsx` (218 строк).
Стек сверху вниз:

1. **`EconomyHeader`** — sticky-шапка с метриками.
   - Заголовок «Экономика» с иконкой `Coins` + бейдж «live» с зелёной точкой.
   - Сетка 5 метрик (2/5 колонок на mobile/desktop):
     `В обороте`, `Курс пульса`, `В банке`, `У юзеров`, `Эмиссия 24ч` (с
     суффиксом «7д: +N»).
2. **Кнопка «Отмены выплат»** (только для owner) — справа, открывает
   панель `EconomyCancellationsPanel`.
3. **Грид карточек категорий** — `EconomyCategoryCard`, 2→3→4→5 колонок
   по ширине. Сейчас 7 категорий: `mining`, `vip_bbs`, `lottery`,
   `bingo`, `monthly_gift`, `referral`, `bbs_bonus`.
4. **Empty-state** «Загрузка экономики…» если категорий нет.

### 1.2 Карточка категории (`EconomyCategoryCard`, 170 строк)
Из чего состоит **каждая карточка** в гриде:

- **Эмодзи** категории (большой, слева вверху).
- **Бейдж OFF** — только когда категория выключена.
- **Мини-тумблер** мастер-свича (вкл/выкл всю категорию) — справа вверху.
- **Название категории** — `category.label`.
- **Главный параметр** (загружается отдельным запросом):
  - подпись topLabel (мелкий лейбл),
  - значение topValue (большой жирный текст), формат `1.2K / 1.5M / число`.
  - Если параметров нет — серый текст «N параметров».
- **Подсказка «Настроить»** + стрелка — появляется при hover.
- **Выезжающая снизу форма подтверждения** (если кликнули по мини-тумблеру):
  - заголовок «🔴 Выключить … ?» / «🟢 Включить … ?»,
  - input для необязательной причины,
  - кнопки «Отмена» / «Подтвердить».

> **Жалоба Ильи (20.05):** «ущербное расположение, дурацкие иконки с
> тумблерами». Большие неоправданные секции. Тумблер и иконка соседствуют
> в углу карточки — выглядит как два контрола рядом без логики. Форма
> подтверждения выезжает прямо в карточке — карточка становится длинной
> и «прыгает».

### 1.3 Модалка деталей категории
Открывается кликом по карточке. Внутри (`CategoryDetailModal` — встроен
в `EconomyPage.jsx`, выносится отдельно при редизайне). Показывает:

- Шапку с названием категории.
- Список под-категорий (subcategories), сгруппирован через
  `EconomySubTable`:
  `base / combo / sprint / shipper / defib` → подпись:
  «📑 Базовые ставки / Комбо-квесты / Спринты / Шиппер-резонанс /
  Дефибриллятор».
- В каждой под-категории — список строк-параметров `EconomyRow`.

### 1.4 Строка параметра (`EconomyRow`, ~150 строк)
**Каждая строка** содержит:

- Название параметра + бейджи «Новое» / «Изменено» (если был апдейт за
  последние 60 с).
- Краткое описание (под названием).
- **Значение** — большое жирное число с unit'ом (₽, %, шт. и т.п.),
  выравнено вправо, фикс. ширина 96px.
- **Тумблер** — отдельная колонка, фикс. ширина 48px, вкл/выкл этого
  параметра (НЕ всей категории).
- **Кнопка «Edit»** — открывает inline-форму редактирования значения.
- **Кнопка «BarChart3»** (история) — открывает `EconomyHistoryPanel`
  справа, лента изменений по конкретному параметру.

### 1.5 Inline-формы (`EconomyEditForm`, `EconomyToggleForm`)
Раскрываются прямо в строке (вытесняют строку вниз). Имеют поля:
- значение (для edit),
- причина (textarea),
- кнопки Сохранить/Отмена.

### 1.6 Боковая панель истории (`EconomyHistoryPanel`)
Slide-in справа. Лента записей: кто/когда/что изменил, кнопка
«Откатить» (если canEdit).

### 1.7 Панель отмен (`EconomyCancellationsPanel`)
Только для owner. Полноэкранная панель с возможностью:
- массовая отмена выплат за период (`EconomyCancelMassModal`);
- точечная отмена по пользователю/строке (`EconomyCancelPointwiseModal`).

## 2. Болевые точки (что Илья назвал «бардаком»)

1. **Тумблер на карточке** соседствует с эмодзи в одном углу — два
   разных контрола без визуальной иерархии.
2. **Inline-форма подтверждения** прямо в карточке — карточка резко
   растёт в высоте, ломая грид. Лучше — модалка или поповер.
3. **«Эти иконки дурацкие»** — `text-2xl emoji` крупный, рядом с мелким
   мини-тумблером 36×20 px и тегом `OFF` высотой 16 px. Микс несочетающихся
   масштабов.
4. **Дубли управления тумблером**: один на карточке, второй в шапке
   `EconomyCategory` (внутри модалки деталей) — два разных стиля
   (карточка 36×20, модалка 44×24). Логично сделать один паттерн.
5. **«Большие неоправданные секции у Шиппера»** — отдельная жалоба
   (20.05). Sub-table «Шиппер-резонанс» внутри модалки Экономики —
   занимает много места без явной структуры. К этому же — долг **cross-link**:
   на экране модуля Шиппер должна быть кнопка «Управление параметрами —
   в Экономике», см. `memory/feedback_module_cross_link.md`.

## 3. Что обязательно сохранить (функционал не теряем)

- **Сетка категорий** на главном (как навигация к группам параметров).
- **Метрики сверху** (Эмиссия, Банк, У юзеров — это «приборная панель»).
- **Мастер-свич категории** (вкл/выкл всю группу) с подтверждающей
  причиной.
- **Тумблер на каждом параметре** (вкл/выкл одного конкретного значения).
- **Inline-редактирование значения** + причина изменения + кнопка
  истории.
- **Панель истории** с возможностью отката.
- **Панель отмен** для owner.
- **Real-time WS-обновления** (метрики, изменения, отмены) с подсветкой
  «Изменено» на 60 с.
- **Разделение прав:** view / edit / cancel (роли owner / deputy / admin).

## 4. Данные, которые рисуем

### 4.1 Метрики чата (сверху)
| Поле | Источник | Формат |
|---|---|---|
| pulse_rate | `/api/economy/metrics.pulse_rate` | `1.23 ₽` |
| bank_balance | то же | `1.2K / 1.5M` |
| users_balance | то же | `1.2K / 1.5M` |
| total_supply | то же | `1.2K / 1.5M` |
| emission_24h | то же | `+1234` / `-1234` (цвет: зелёный/красный) |
| emission_7d | то же | `+1234` (доп. метка) |

### 4.2 Категория (карточка)
- `key` (machine id, для роутинга API),
- `label` (русское название),
- `is_enabled` (bool),
- `rows_count` (число параметров),
- **доп. fetch** на `/api/economy/settings?category=<key>` для первой
  строки (главный параметр карточки).

### 4.3 Параметр-строка
- `key`, `label`, `description`, `value`, `unit`,
- `is_enabled`, `created_at` (для бейджа «Новое» 24ч),
- `subcategory` (base / combo / sprint / shipper / defib),
- `history_count`.

### 4.4 Подкатегории внутри категории
Группа `subcategory` — это **сейчас 5 значений**:
`base / combo / sprint / shipper / defib`. На редизайне можем оставить
группировку или объединить с базой (твоё решение).

## 5. Действия пользователя (что можно делать)

| Уровень | Действие | Кто |
|---|---|---|
| Категория | Включить/выключить всю категорию (с причиной) | owner+deputy |
| Категория | Открыть подробности | все, кто видит |
| Параметр | Изменить значение (с причиной) | owner+deputy |
| Параметр | Включить/выключить параметр (с причиной) | owner+deputy |
| Параметр | Открыть историю изменений | owner+deputy |
| История | Откатить изменение | owner+deputy |
| Отмены | Массовая отмена выплат | только owner |
| Отмены | Точечная отмена | только owner |

## 6. Связи с другими модулями (важно)

- **Шиппер** — в Экономике есть под-категория `shipper` (Шиппер-резонанс).
  По решению 19.05: если модуль «Шиппер» в хабе отключён, его строки в
  Экономике должны быть **disabled-визуально** (не редактируемы). На
  экране модуля Шиппер — кнопка-ссылка «Управление параметрами начислений —
  в Экономике» (см. `feedback_module_cross_link`).
- **Спринты / Комбо** — отдельные карточки в хабе «Модули», но их
  параметры лежат в Экономике (под-категории `combo`, `sprint`). Тот же
  принцип disabled-визуала, если модули выключены.
- Общая память про это: `memory/modules_hub_state_2026_05_19.md`,
  `memory/module_connect_enforcement.md`.

## 7. Дизайн-система (что использовать)

- **Скругления:** `rounded-2xl` (16 px) для кнопок, `rounded-3xl` (24 px)
  для крупных карточек/секций. Уже используются — продолжаем.

  `text-cta` / `bg-ok` и т.п. уже работают.
- **Готовые компоненты в `components/shared/`:**
  `Button.jsx`, `Toggle.jsx`, `Card.jsx`, `ConfirmDialog.jsx`,
  `StyledSelect.jsx`, `DateTimePicker.jsx`, `Stepper.jsx`,
  `RichTextEditor.jsx`, `MediaBlock.jsx`. **Тумблер уже есть** —
  использовать `Toggle.jsx` везде, не плодить кастомные.

  `Gem`, `Repeat2`, `Landmark`, `Users`, `TrendingUp/Down`, `Ban`,
  `ChevronDown`, `ArrowRight`, `Edit`, `BarChart3`, `PlusCircle`.
- **Темы:** один light-режим (тёмная удалена 19.05, см.
  `decision_single_theme_2026_05_19`).

   накопительную группировку через подзаголовки или плоский список с
   фильтром-табами?
3. **Inline-редактирование значения** vs модалка vs боковая панель —
   что приятнее на твой вкус?
4. **Метрики** — сейчас 5 равноценных. Может быть hero-метрика (одна
   крупная) + ряд мелких? Какая хеоро (Эмиссия 24ч? Курс?).
5. **Empty-state** «Загрузка экономики…» с 💰 — оставляем или меняем на
   скелетон?
6. **Модалка отмен выплат** — сейчас на отдельной кнопке справа сверху.
   Можно ли её спрятать в меню «…» рядом с метриками (чтобы не было

Чтобы я мог сразу разнести по коду:
1. **Главный экран** — финальный layout (сетка, размеры, отступы).
