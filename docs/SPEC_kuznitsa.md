> Жители на сегодня: Гримуар Загадок, Регистрация-конструктор.
> Очерёдность реализации: первый житель — после Биллинга.

## 1. Что такое Кузница

**Отдельный спец-раздел внутри «Модули»** на сайте. Не обычный модуль, а **контейнер** для крупных конструкторских инструментов — где владелец собирает не настройки, а целые подсистемы (загадки с наградами, динамические сценарии регистрации, кастомные команды, и т.д.).

**Отличие от обычных модулей в Хабе:**
| | Обычный модуль | Модуль Кузницы |
|---|---|---|
| Что делает | Настройка готовой механики (вкл/выкл, параметры) | Конструктор — владелец СОБИРАЕТ механику с нуля |
| Сложность UI | Карточка с тумблерами | Полноценный редактор/конструктор |
| Время на настройку | Минуты | Часы-дни |
| Тариф | Free/Paid | Чаще Paid (это инструмент «сделай сам что захочешь») |

## 2. UX-фишка — «строительная лента» в hover

При наведении на карточку модуля Кузницы (или на сам раздел «Кузница») — поверх карточки появляется **полупрозрачная жёлто-чёрная диагональная штриховка** в стиле строительной/предупреждающей ленты (как «УВАЖАЕМЫЕ, ВНИМАНИЕ — РАЗРАБОТКА»).

**Зачем:**
- Сразу видно «это не просто кнопка с настройкой — это конструктор, тут надо разбираться»
- Визуальная единица раздела — все модули Кузницы выглядят как «строящиеся», подчёркивает «здесь вы творите»
- Тематически попадает в само название «Кузница» (молот, искры, работа)

**CSS-эскиз:**
```css
.kuznitsa-module-card:hover::before {
  content: '';
  position: absolute; inset: 0;
  background: repeating-linear-gradient(
    45deg,
    rgba(255, 200, 0, 0.85) 0 12px,
    rgba(0, 0, 0, 0.85) 12px 24px
  );
  opacity: 0.55;
  mix-blend-mode: multiply;
  pointer-events: none;
  border-radius: inherit;
  animation: kuznitsa-tape 8s linear infinite;
}
@keyframes kuznitsa-tape {
  from { background-position: 0 0; }
  to   { background-position: 48px 0; }  /* медленный сдвиг — «работает» */
}
```
Поверх ленты — иконка молотка/искр или подпись «Конструктор» (lowercase, моноширинная — стилистика «инженерного журнала»).

## 3. Жители (заявлено)

### 3.1 🧩 Гримуар Загадок (первый житель)
Полная спека: `docs/IDEAS_BACKLOG.md` #3 + `docs/DESIGN_engagement_engine.md`. Стол Крафта — UI внутри этого модуля для создания загадок с пулом наград (Бронза/Серебро/Золото/Тайные). XL по размеру, зависит от engagement-движка #0, сезонов #7, промокодов #8, биллинга.

### 3.2 📝 Регистрация-конструктор (второй житель)
Перевозим из отдельной идеи. Память: `idea_custom_registration_builder.md`. Владелец на сайте собирает свою анкету из блоков (вопрос/выбор/фото/согласие), бот исполняет схему. Также XL — фактически **движок динамических сценариев** платформы (потом переиспользуется опросами/кастом-командами).

Рекомендованная фазировка (из исходной идеи 21.05):
1. Шаблоны + ограниченная кастомизация (3-4 пресета, вкл/выкл вопросы, правка текстов) — 80% ценности дёшево
2. Линейный блок-конструктор без ветвления
3. Ветвление + маппинг полей (только если 1-2 востребованы)

## 4. Куда встаёт в общей очереди

```
Завершение модулей → Метрики V1 → Клон настроек → Биллинг
                                                     ↓
                                            🔨 КУЗНИЦА (раздел появляется)
                                                     ↓
                                            Гримуар Загадок (XL)
                                                     ↓
                                            Регистрация-конструктор (XL)
```

Сам раздел «Кузница» можно открыть **до** реализации жителей — будет пустой раздел с описанием «здесь будут конструкторы» + UX-эффект ленты. Это **создаёт ожидание и понимание места в IA**.

Однако сами жители — XL, после Биллинга (как и сама спека Гримуара требует).

## 5. Открытые вопросы (обсудить когда дойдём)

1. **Положение в сайдбаре:** Кузница — вкладка внутри «Модули» (под отдельной подсекцией) или отдельный пункт сайдбара?
2. **Тариф:** доступ ко всей Кузнице платный целиком или каждый житель отдельно?
3. **Иконка раздела:** молот? шестерня? искра? Подобрать в дизайне.
4. **Анимация ленты:** медленный сдвиг или статика? Учесть `prefers-reduced-motion`.
5. **Заглушка-карточка** для будущих жителей — «Скоро: Конструктор команд» с лентой постоянно — или вообще не показывать пустых?
