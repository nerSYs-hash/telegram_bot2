## 5. Как двигаться без «мысли не в кучке»

**Правило фокуса** — в одной сессии работаем **только над одной фазой**. Между сессиями не прыгаем.

**Правило входа в сессию:**
1. Открыть `dev_backlog_index.md` (memory) и этот ROADMAP → понять где остановились
2. Спросить «продолжаем X или переключаемся?»
3. Если новая идея — она идёт в backlog, не ломает текущую фазу

**Правило закрытия:**
- Каждая фаза = merge в main + запись в memory о том, что закрыли
- После закрытия фазы — обновить статусы в этом файле
