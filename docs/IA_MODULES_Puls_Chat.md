## Принцип

Весь сайт — модули. Владелец сам собирает свой инструмент. Для нас
каталог = ещё и карта монетизации (free / paid → дешёвый/средний/дорогой).
Вместо кучи вкладок в сайдбаре — один хаб «Модули».

## Сайдбар = 3 пункта (всё остальное убрать оттуда)

1. **Обновления** → «карта обновлений» (roadmap/changelog-карта, не плоский
   список). Сейчас просто список — переделать в карту.
2. **Модули** → ХАБ:
   - Сверху под-навигация компонентом **«underline · бренд-линия»**
     (скрин 102042: горизонтальные таб-ссылки с бренд-подчёркиванием) —
     список секций.
   - Клик по секции → грид **карточек-модулей** → подключаешь нужные.
   - В уже подключённых модулях — **пунктирная кнопка «подключить модуль»**:
     либо переход в каталог, либо инлайн-поповер подключения тут же.
3. **Система** → ПЕРЕРАБОТАТЬ. Сейчас «всё намешано, раздражает».
   Разобрать что там, оставить только настройки уровня платформы.

## Что становится модулями (под «Модули»)

| Модуль | Заметка |
|---|---|
| Статистика и графики | в работе — каталог виджетов (STATS_SPEC, #7/#8) |
| Экономика | **нужна переработка** (см. ниже про «Функции бота») |
| Активности | каждая активность — подключаемый суб-модуль |

| **Журнал** | модуль; внутри владелец сам подключает суб-модули: вход/регистрация, выход, смена фото и т.д. |

## Долги/проблемы, которые всплыли (бэклог)

- **«Функции бота» дублируют отключение функций** — тот же механизм, что в
  Экономике. Несостыковка: в Экономике при отключении просят **причину**,
  в «Функциях бота» — нет. Унифицировать: один механизм тумблеров модулей
  + единое поведение (причина при отключении — решить, нужна везде или нет).
- **AI-помощник** — ✅ УДАЛЁН с сайта 19.05 (import, иконка, пункт меню,
  страница, `components/PromptTranslator.jsx`).
- **Регистрация** — кастомизация/редактирование ещё НЕ сделаны.
- **Кузница / «стол разработки»** — ещё НЕ сделана.
- Тёмная тема удалена навсегда (см. `decision_single_theme_2026_05_19`).

## Предлагаемая последовательность (моя оценка)

Направление верное и ложится на SaaS-пивот. Риск один — делать всё разом
= хаос. Поэтому по шагам, каждый шаг отдельным коммитом, сборка зелёная:

1. **Зафиксировать контракт** (этот файл) — ✅ + AI-помощник снести ✅.
2. Каркас хаба «Модули»: под-нав «underline·бренд-линия» + грид карточек
   + пунктирная «подключить модуль». Механизм тумблеров — единый
   (`section_toggles`, RBAC, причина при отключении — единое правило).
3. Перенести в хаб первый модуль целиком как эталон — **Статистика**
   (каталог #7 + ленивый рендер #8). На нём отрабатываем паттерн.
4. По одному переносить остальные секции в модули: Триггеры → Пресс-релизы
   → Шиппер → **Экономика (с переработкой)** → Активности.
5. **Журнал как модуль** + его суб-модули (вход/выход/фото/регистрация).
6. **Система** — разбор и чистка (оставить платформенное).
7. Сайдбар ужать до 3 пунктов; **Обновления → карта обновлений**.
8. Бэклог: кастомизация регистрации, Кузница/стол разработки.

> Каждый перенос секции в модуль = заодно метка free/paid/тариф
> (внутренняя, не для пользователя).
