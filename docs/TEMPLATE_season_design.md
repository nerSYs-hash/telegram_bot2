# 🗓️ Шаблон разработки сезона (процесс, не фича)

> Это **рабочий шаблон/чек-лист**, по которому проектируется каждый новый сезон геймификации.
> Не идея для бэклога — копируй этот файл при старте проектирования конкретного сезона.
> Связано с модулями: Ачивки (`IDEAS_BACKLOG.md` #1), Гримуар Загадок (#3), Сезонные ачивки.

---

**Название Сезона:** [например, «Сезон Древних Свитков», «Кибер-Легенды»]
**Ключевая дата запуска:** [дата]
**Длительность:** [дней/недель/месяцев]
**Краткое описание:** [1–2 предложения о теме/концепции]

## 1. Идея сезона
- **Основная концепция / тематика:** мир, история, персонажи, сеттинг (отражается в текстах, квестах, наградах).
- **Ключевые элементы нарратива / лор:** какие истории раскрываются через тексты квестов, сообщения бота, описания наград.
- **Изюминка сезона:** что делает его особенным (новые текстовые механики, стиль диалогов, типы загадок).

## 2. Промо-материалы
- Точное название ивента/сезона (для анонсов).
- Ключевой арт / заставка + промт для генерации.
- Текстовый анонс / вступительное сообщение бота.
- Баннеры / иконки для соцсетей / сайта.

## 3. Функционал (квесты / задания)
- **Система прогрессии (сезонный путь):** очки/цепочки квестов, число уровней/рангов.
- **Открытые задания** (всем): ежедневные / еженедельные / сезонные; типы действий; цель — удерживать активность.
- **Закрытые задания** (премиум/особый статус): сложнее, эксклюзивный контент.
- **Сюжетные цепочки:** раскрывают лор; открытые или закрытые.

## 4. Магазин / обмен наград
- Уникальные товары сезона (роли, стикеры, титулы, секретные команды); методы получения.
- Стандартные товары / постоянная ротация.
- Частота ротации магазина.
- Спец-предложения / бандлы (наборы, стартовые скидки).

## 5. Титулы / роли / статусы
- Эксклюзивные титулы сезона + условия получения.
- Постоянные новые титулы в общую систему.
- Визуализация (префиксы/суффиксы, значки/эмодзи в профиле).

## 6. Награды и за что
- За прогресс (бесплатный трек) / (премиум трек).
- За отдельные задания/челленджи.
- За сезонные ачивки.
- Конечная награда сезона (ультимативный титул/предмет/анимация).
- За рейтинг / топ-игроков.

## 7. Ивенты внутри сезона
- Тематические ивенты (1–3 крупных) + механики + сроки.
- Нетематические/повторяющиеся активности (двойные очки, скидки, командные викторины).
- Социальные ивенты (командные челленджи, коллективные загадки).
- Ивенты сообщества (конкурсы вне бота).

## 8. Что ещё учесть
- **Экономика/баланс наград:** влияние на внутреннюю экономику (новые валюты, источники/траты, цены).
- **Технические аспекты:** новые команды, интеграции, масштабирование при росте активности.
- **Обратная связь и мониторинг:** как собирать фидбэк; метрики успешности (активность, вовлечённость, покупки).
- **Пост-сезонный контент:** что с эксклюзивом после сезона (уходит/в ротацию/позже в др. формате).
- **Ресурсы:** время на разработку/поддержку (код, тексты, арт, маркетинг).
- **Синхронизация:** если бот на нескольких платформах — синхронизация прогресса/наград.
