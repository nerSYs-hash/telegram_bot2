## Архитектура (идея Ильи, принята)

- Модули → новая карточка **«Статистика и графики»** = каталог виджетов
  с пер-workspace тумблерами (механизм `section_toggles`, как в Экономике).
- По умолчанию все виджеты ВЫКЛ. Пользователь сам включает нужное
  (с уважением RBAC — кто может включать).
- Раздел **Статистика** = ленивый рендер ТОЛЬКО включённых виджетов
  как полноценных графиков. light-only, токены DS, recharts +
  кастомный heatmap-грид (в recharts heatmap нет).
- «Сырые» виджеты (нет данных) показываем в каталоге как «Скоро».

## Бэкенд (факты)

- `/api/stats?period=` — FastAPI (`api.py::_compute_stats`), single-tenant
  стиль (нет фильтра workspace_id). Период: today/yesterday/week/month/year.
- Сейчас отдаёт: `period, periodLabel, bankBalance, pulseRate, difficultyK,
  activeUsers, totalUsers, messages, pulsesMined, joined, left, history[],
  healthIndex, indices{oksp,sdsp,cho,media,korp,kopyup}`.
- `user_stats` (день×юзер×ws): `total_messages, total_chars, total_words,
  reactions_given, reactions_received, replies_sent, replies_received,
  mentions_received, media_sent, other_threads_posts, pulses_mined`.
- `users.joined_at` (глобально), `transactions(return_on_leave)` = вышедшие,
  `topics` = per-thread счётчики. **Гранулярность — ДЕНЬ, не час.**
- Excel: `/api/stats/export?period=`.

## 11 виджетов (дедуп: вкладки Час/День, Месяц/Неделя, hover — это варианты одного)

Каждый виджет: заголовок · `?`-подсказка (hover, текст ниже) · экспорт CSV · light/DS.

1. **Статистика по пользователям** — combo: бары Новые/Покинувшие/Удалённые
   + линия Всего (dual Y). Чипы итогов Всего/Онлайн.
   *Подсказка:* Всего новых = присоединившиеся; Покинувшие = вышли сами;
   Удалённые = удалены админами/ботом (приветствие, face-контроль, фильтр,
   /kick /ban); Всего = всего участников; Онлайн = онлайн сейчас.
   **Данные:** joined ✅, left ✅, Всего ✅(вывод); Удалённые 🟡(нужен источник
   модерации), Онлайн ❌(Telegram не даёт).
2. **Количество сообщений по дням** — группир. бары: сообщений + юзеров.
   *Подсказка:* Кол-во сообщений = всего написано; Кол-во пользователей =
   уникальных писавших. **Данные:** ✅ полностью.
3. **Коэффициент вовлечённости** — area %, вкладки Месяц/Неделя.
   *Подсказка:* соотношение пишущих к общему числу участников.
   **Данные:** ✅ (distinct writers / total_users).
4. **Активные пользователи** — heatmap, вкладки Час (часы×дни) / День
   (дни-недели×недели). *Подсказка:* по часам/дням = написали ≥1 сообщ.
   **Данные:** День ✅; **Час ❌ (нет почасовых)**.
5. **Сообщения** — heatmap, Час/День; насыщенность = объём.
   **Данные:** День ✅; **Час ❌**.
6. **Сводная новых по дням** — бары Всего новых/Новые/Вернувшиеся/Приглашённые.
   *Подсказка:* Новые = сами (поиск/ссылки); Вернувшиеся = вышли и вступили
   снова; Приглашённые = реф-ссылки/«добавить участников».
   **Данные:** Всего ✅; атрибуция 🟡 (рефералы есть, «вернувшиеся» — нужна история).
7. **Первое сообщение в чате** — бары: в 1-й день / после 1-го дня.
   **Данные:** ✅ вычислимо (joined_at vs первая дата сообщения).
8. **Статистика по сообщениям** — линия Всего + бары Комментариев/Ответов/
   Отредактированных. **Данные:** Всего ✅, Ответов ✅; Комментариев 🟡
   (other_threads_posts?); **Отредактированных ❌ (не пишется)**.
9. **Статистика активности пользователей** — линия MAU/Всего активных +
   бары Комментарии/Реплаи/Отредактировали/со ссылкой/с упоминанием.
   **Данные:** Реплаи ✅, Упоминания ✅; **со ссылкой ❌, отредактировали ❌**.
10. **Сводная по активным** — бары Новые(<14дн, ≥1 сообщ)/Постоянные(>30дн)/
    Активные(прочие). **Данные:** ✅ вычислимо (joined_at + user_stats, тяжёлый запрос).
11. **Ряд mini-KPI** (4 компактных): Активные/день (Среднее WAU),
    Активные/час (Среднее DAU), Сообщений/день (среднее/всего),
    Сообщений/час (среднее) — каждая с мини-барами.
    **Данные:** дневные ✅; почасовые ❌.

## Пробелы → бэкенд-доработки (этап 2+)

- Почасовое бакетирование сообщений/активных (новая таблица или hour-колонка).
- Учёт `edited` сообщений, `links` в сообщениях — новые колонки/события.
- «Удалён ботом/админом» — событие модерации в stat-лог.
