# Puls Chat — Design Brief (портативный мост)

> **Зачем этот файл.** Claude Code (архитектор: токены/размеры/логика) и
> Claude в дизайн-вкладке (визуализатор) не интегрированы. Этот документ —
> мост: скопируй его целиком в дизайн-сессию, и концепты рисуются строго
> по НАШИМ значениям, а не «из головы». Все числа ниже — реальные из
> `Admin_SITE/index.css` и наших дизайн-заметок, либо точные из референса
> visionOS, который выбрал Илья.

---

## 0. Решение: ДВЕ темы, одна система

Puls Chat = **dark (по умолчанию) + дневная light**, переключатель
(умный sun/moon-тумблер). Рисуем НЕ два разных дизайна, а **один набор
семантических токенов**: общие — бренд-градиент, семантика, радиусы,
спейсинг, типографика, моушн; меняются только **холст / поверхность /
текст / сила свечения**.

Каждый концепт-экран отдавать **в обоих режимах** (dark и light), чтобы
видеть паритет. Компоненты — на CSS-переменных (паттерн уже есть для
glow), тему переключает класс на `<html>` (`.theme-dark` / `.theme-light`).

---

## 1. Суть бренда

**Puls Chat** = «спокойно и дорого». Не терминал трейдера, не радуга.
Тёмный холст со светом из угла, стеклянные карточки, крупные числа,
один сквозной мотив — **пульс** (волна/кольцо сердцебиения).

- **North star:** концепт «Aaru» (тёмный, аврора из угла, стеклянные
  карточки, кольца прогресса).
- **Источник семантики:** палитра visionOS (точные значения ниже).
- **Урок сдержанности:** концепт «Task Board» (минимум цвета, максимум
  воздуха).
- **Анти-паттерн:** «AdminDASH» (всё-везде-сразу, плотность). НЕ так.

## 2. Цветовые токены (точные)

### 2.1 Бренд-glow (уже в коде — канон, не менять)
Вращающийся conic-gradient (Aceternity), `index.css`:

- Кнопки: `--glow-from #3b82f6` → `--glow-via #a855f7` → `--glow-to #3b82f6`
- Карточки: `#60a5fa` → `#a855f7` → `#60a5fa`

Это «пульс»-свечение синий→фиолетовый. Бренд-акцент = **этот градиент**.

### 2.2 Семантика (значения visionOS — из референса Ильи)
| Назначение | Цвет | HEX | RGB |
|---|---|---|---|
| Успех / **чат подключён** / опубликовано | Green | `#32D74B` | 50,215,75 |
| Внимание / экономика / титулы | Orange | `#FF9F0A` | 255,159,10 |
| Акцент-жёлтый (награды) | Yellow | `#FFD60A` | 255,214,10 |
| Опасно / удаление / **чат отключён** / ошибка | Red | `#FF453A` | 255,69,58 |
| Основной CTA / интерактив | Blue | `#0A84FF` | 10,132,255 |
| Пресс-релизы / админ-модули | Purple | `#BF5AF2` | 191,90,242 |
| Брендинг / подписи | Pink | `#FF375F` | 255,55,95 |
| Позитивные метрики | Mint | `#66D4CF` | 102,212,207 |
| Нейтраль / disabled | Gray | `#98989D` | 152,152,157 |

Принцип неон-референса: каждый цвет имеет пару **«свет / тень»** — на
тёмном фоне акцент = base, его свечение = тот же hue, alpha ~0.35,
blur 24–40px.

### 2.3 Холст — DARK (`.theme-dark`, по умолчанию)
- База: `#0A0A0F` (почти чёрный с лёгкой синью).
- Поверхность/карточка (стекло): `rgba(255,255,255,0.04)` +
  `backdrop-blur(16px)` + бордер `1px rgba(255,255,255,0.06)`.
- **Аврора из угла:** поверх базы `radial-gradient` от верх-правого угла,
  бренд `#3b82f6`→`#a855f7`, alpha 0.10–0.15, большой радиус. Никаких
  плоских серых заливок.
- Текст: основной `#F4F4F6`, вторичный `#9CA3AF`, лейблы `#6B7280`.

### 2.4 Холст — LIGHT (`.theme-light`, дневная)
Зеркало dark на тех же семантических именах токенов:
- База: `#F6F7F9` (мягкий off-white, не чистый белый — меньше бликов).
- Поверхность/карточка: `#FFFFFF`, бордер `1px rgba(15,23,42,0.06)`,
  мягкая тень `0 1px 3px rgba(15,23,42,.06)` (стекло-blur на свету
  читается мутно → тень вместо него).
- **Аврора:** та же бренд-радиалка, но alpha **0.04–0.06** (намёк, не
  заливка), иначе грязнит.
- Текст: основной `#111318`, вторичный `#4B5563`, лейблы `#9CA3AF`.
- Семантика: hue те же. Для **заливок/точек** — яркие значения §2.2.
  Для **текста/иконок на свету** — затемнённые варианты ради контраста
  AA: green `#248A3D`, red `#D70015`, blue `#0066CC`, orange `#C7700A`,
  purple `#8944AB`, pink `#C9134A`.

### 2.5 Семантические имена токенов (одни на обе темы)
Компонент знает только имя, не цвет. Тема подменяет значение:
`--bg`, `--surface`, `--border`, `--text`, `--text-dim`, `--label`,
`--brand-from`, `--brand-via`, `--brand-to`, `--ok`, `--warn`, `--danger`,
`--cta`, `--accent-press`, `--accent-brand-pink`, `--neutral`.
Переключатель = смена класса на `<html>` → все экраны меняются разом.

## 3. Геометрия

- **Радиус-канон: 16px** (`rounded-2xl`) — всё: карточки, кнопки, инпуты,
  пилюли (кроме круглых). Glow-псевдоэлемент: `inset:-2px` → `border-radius:18px`.
- **Спейсинг-шкала:** 4 / 8 / 12 / 16 / 24 / 32 / 48. Паддинг карточки 24.
  Гэп между карточками 16–24.
- **Сайдбар:** expanded **248px** / collapsed **80px**, collapse с
  пружиной. Полная спека размеров — **§5a**.
- Сетка дашборда: 12 колонок, крупные карточки, много воздуха (как Aaru),
  НЕ дробить на 30 виджетов (анти-AdminDASH).

---

## 4. Типографика

| Роль | Стиль |
|---|---|
| Большое число / display | 40–56px, `font-black`, tabular-nums |
| Заголовок экрана | text-xl, `font-black` |
| Заголовок секции | text-sm, `font-bold` |
| Контент / body | text-sm |
| Лейбл / eyebrow | `text-[10px] uppercase tracking-widest`, цвет `#6B7280` |

Шрифт — system / Inter-подобный. Цифры в метриках — моноширинные
(tabular), чтобы не «прыгали».

## 5. Сигнатурные компоненты (анатомия)

Уже есть в `Admin_SITE/components/shared/`: Button, ButtonGroup, Toggle,
StyledSelect, Card, Stepper. Тёмная тема = переопределение токенов, НЕ
переписывание API.

- **Card (стекло):** bg `rgba(255,255,255,0.04)`, бордер `0.06` white,
  blur 16, радиус 16; hover → вращающийся glow-бордер (`.pulse-card-glow`,
  4s) + lift `translateY(-2px)` 200ms.
- **Button:** варианты primary/secondary/ghost/danger/success; hover/focus
  → `.pulse-btn-glow` (2.4s). Loading: спиннер + «Сохраняю…». Success:
  галочка pop 350ms.
- **Status-pill «чат» (нужен для V1.17.0h):**
  - Подключён → точка `#32D74B` + мягкое пульсирующее кольцо (1.6s).
  - Отключён → точка `#FF453A`, без пульса, текст приглушён.
  - Реконнект-восстановлен → короткий «↻» + green.
- **Stat-ring:** круг прогресса, обводка = бренд-градиент, центр —
  большое tabular число + лейбл.
- **Sidebar:** полная спека с размерами — **§5a** (отдельный компонент,
  делаем ПЕРВЫМ в «цехе»). Иконки outline Lucide-style stroke 2,
  hover-glow в brand-hue (см. «contextual hover glow»).

## 5a. Sidebar — полная спека (размеры реальные, из 2 референсов)

Источник чисел: @alenn.design (248px) + Storeify «Spacing Cheat Sheet»
(240/80px). Гармонизировано под наши токены (радиус 16, типошкала §4,
семантика §2, обе темы).

**Размеры контейнера**
- Ширина: expanded **248px**, collapsed **80px**.
- Внешние паддинги: бока **16px**, верх **24px**, низ **16px**.
- Поверхность: dark — `--surface` стекло; light — `#FFFFFF` + мягкая
  тень; правый бордер `1px --border`.
- Кнопка collapse: круглая **28px**, верх-право, spring 220ms.

**Бренд-строка (верх)**
- Высота **40px**: лого-марка 28–32px + вордмарк SemiBold **20px**.
- Collapsed: только марка, по центру. Ниже — **16px** до поиска.

**Поиск**
- Полная ширина, высота **40px**, радиус 16, иконка 20px + плейсхолдер
  text-sm (SemiBold 14px). Collapsed → иконка-кнопка 40px.
- Ниже — **24px** до первой секции.

**Лейбл секции** («Menu»/«Group»)
- `text-[11px]` SemiBold uppercase tracking-widest, цвет `--label`.
- **16px** над первым пунктом; разделение секций **24px**.

**Пункт меню**
- Высота **40px**, вертикальный гэп между пунктами **4px**, радиус 16.
- Активная «пилюля» = ширина − 32 (≈ **216px** в expanded).
- Иконка 20–22px outline (stroke 2), гэп иконка→лейбл **12px**,
  лейбл text-sm SemiBold **14px**.
- Состояния: default `--text-dim`; hover bg white/чёрн `.04` + `--text`;
  **active** = заливка (`.06`) + `--text` + иконка в `--cta`;
  focus-visible — glow §6.
- Бейдж-счётчик: справа, min **18–20px**, радиус full, bg `--danger`,
  текст white SemiBold **12px** («12», «14»). «Новое» = только точка.
- Пункт с подменю: шеврон `›` справа, поворот при раскрытии 150ms.
- Разделитель групп: `1px --border`, вертикальный отступ 16px.

**Футер (прибит к низу)**
- Тема-тумблер segmented **104×32**, sun/moon, SemiBold 16px;
  **16px** над строкой юзера.
- Строка юзера высота **56px**: аватар **40px** + имя text-sm SemiBold
  + email `text-[11px] --label` + logout-иконка 20px.
- Collapsed: только аватар; logout по hover.

**Collapsed (80px)**
- Иконки по центру, лейблы скрыты, hover → тултип (тёмная пилюля,
  white, +8px offset). Бейджи → точка в углу иконки. Тема → 1 кнопка.

**Моушн (в бюджете §6a)**
- collapse/expand ширины 220ms spring (лёгкая); fade лейблов 120ms;
  шеврон 150ms; hover-bg пункта 150ms.

## 6. Моушн-токены (точные, из `index.css`)

- Glow кнопки: `pulse-btn-rotate` 2.4s linear infinite (только hover/focus).
- Glow карточки: `pulse-card-rotate` 4s linear infinite.
- Success-галочка: pop 350ms `cubic-bezier(.34,1.56,.64,1)`.
- Активный шаг Stepper: `pulse-step` 1.8s ease-in-out.
- Появление glow: opacity 200ms (btn) / 300ms (card) ease.
- Hover-lift карточки: `translateY(-2px)` 200ms ease.
- **Пульс-мотив (новый):** «сердцебиение» 1.6s ease-in-out infinite —
  кольцо/волна слегка дышит (scale 1→1.08→1 + glow).

## 6a. Motion Principles — бюджет сдержанности (жёсткие рамки)

Не вкусовщина — рамки в контракте. Анимация принимается, ТОЛЬКО если
ложится в один из примитивов ниже.

- **Длительности:** микро 120–200ms · стандарт 200–350ms · амбиент-петли
  1.6–4s. Реальные из `index.css` (glow 2.4/4s, pop 350ms, step 1.8s) —
  это потолок, новое влезает в бюджет.
- **Двигать можно только:** `opacity`, `transform: translateY ≤2px`,
  `scale ≤1.08`, прозрачность glow. Больше ничего.
- **Spring** `cubic-bezier(.34,1.56,.64,1)` — ТОЛЬКО подтверждение успеха.
- **Запрещено:** прыгающий layout, parallax везде, спиннеры кроме
  loading, авто-играющее отвлекающее движение, мигание.
- **Триггер:** только hover / focus / смена состояния. Ничего «само».
- **`prefers-reduced-motion`:** не-смысловые анимации выключаются,
  смысловые (loading/success) — мгновенная не-моушн форма.

## 7. Мотив «пульс»

Сквозной графический элемент = стилизованная ЭКГ-волна + концентрическое
светящееся кольцо (взято из неон-референсов и графиков). Где живёт:
лого-марка, лоадеры, индикатор live-активности, пустые состояния,
пульсирующее кольцо у статуса «подключён». Бренд сам себя дарит.

## 8. Готовый промпт для дизайн-вкладки (копировать ниже)

```
Ты — визуальный дизайнер продукта Puls Chat. Отдай рабочий HTML/CSS
(Tailwind ок) артефакт. Используй ТОЛЬКО токены из этого брифа
(HEX, радиус 16px, спейсинг-шкала, типографика, моушн §6).

ДВЕ темы из одного набора CSS-переменных (§2.5). Класс на <html>:
.theme-dark (по умолчанию) — холст #0A0A0F + аврора #3b82f6→#a855f7
alpha 0.10–0.15, стеклянные карточки rgba(255,255,255,0.04) бордер 0.06.
.theme-light — холст #F6F7F9, карточки #FFFFFF + мягкая тень, аврора
alpha 0.04–0.06, текст #111318.
Семантика — таблица visionOS (на свету текст-варианты §2.4).
Сквозной мотив «пульс» (волна/кольцо). Сдержанно и дорого.

Вверху справа — рабочий sun/moon-тумблер, реально переключающий
.theme-dark/.theme-light на лету (один и тот же экран, обе темы).

Сделай концепт экрана: <ЭКРАН>.
Состояния обязательно показать: <состояния>.
Формат: десктоп 1440 и мобайл 390, каждый — в обеих темах.
```

### Первые экраны (предлагаю порядок — стыкуется с бэкендом V1.17.0h):
1. **Dashboard home** — приветствие, 3–4 крупные метрики (stat-ring),
   список сообществ, активность «пульс»-волной.
2. **Чаты сообщества** — карточки чатов со status-pill: подключён /
   **отключён** / реконнект-восстановлен, роль (Главный/Админ/Журнал).
   (Прямо визуализирует то, что мы только что собрали в бэке.)
3. **Подключение чата** — экран онбординга («в готовое сообщество» vs
   «новое отдельное») — понятные карточки-выборы.
4. Лендинг Puls Chat (later).
