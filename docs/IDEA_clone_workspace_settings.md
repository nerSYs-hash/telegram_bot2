# IDEA: Клон настроек workspace (1-в-1)

> Запрос Ильи: 2026-05-24. Решение по фазе: **после Метрик V1, до Биллинга** (фаза «средний порядок» между B-завершением и E).

## Зачем

Владелец с несколькими TG-сообществами получает **одну кнопку «Скопировать настройки этого чата в другой»**. Сценарии:
- Эталонный Pulse Москва → запускаем Pulse Питер за минуту
- Тестовый ws → продакшен ws (отладил конфиг → залил)
- Несколько одинаковых клиентских чатов одного владельца

Стратегически — рычаг **ретеншна и upsell**: владелец легче разворачивает второй ws → платит за второй tariff. Без этой фичи каждое новое сообщество = ручная настройка с нуля.

## Решения (приняты 2026-05-24)

| Вопрос | Решение |
|---|---|
| Режим | **Клон 1-в-1** (без именованных шаблонов и Pulse-пресетов на старте) |
| Данные людей | **Никогда не копируем** (балансы, XP, транзакции, помощники, члены — всегда новые в target ws) |
| Когда делаем | **После Метрик V1, до Биллинга** |

## Что копируется (только настройки, не контент и не люди)

| Что | Таблица | Заметка |
|---|---|---|
| Включённые модули | `module_toggles` | прямой INSERT с заменой `workspace_id` |
| Параметры Экономики | `economy_settings` | прямой клон |
| Тумблеры построчно | `section_toggles` | прямой клон |
| Триггеры (правила) | `triggers` | прямой клон + сброс `chat_id`/`thread_id` |
| Триггеры (медиа) | `trigger_media` | 🟡 `file_id` привязан к боту+чату → авто-рескачать при первом использовании в новом ws (флаг `needs_refresh=1`) |
| BBS категории/VIP | `bbs_categories`, `bbs_vip_*` | прямой клон |
| Журнал — категории/хештеги | `journal_categories` | прямой клон |
| Гороскопы (когда модуль) | TBD | прямой клон |
| Пресс-релиз — брендинг/шаблоны | `press_release_branding`, `press_release_templates` | прямой клон (медиа — как у триггеров) |

## Что НЕ копируется (явный список запрета)

- `users`, `user_stats`, `user_stats_hourly`, `transactions`, `users_xp_log` — данные людей
- `workspace_members` — помощники привязаны к ws и его людям
- `bot_chats` — роли чатов уникальны на ws (main/admin/journal — других чатов)
- `news_*` — это контент, не настройки
- `stat_events_log`, `moderation_log` — история событий
- `workspaces.icon_url` — иконка авто-подтянется из нового TG-чата

## Технические сложности

1. **`file_id` медиа** привязан к {бот, чат}. При копировании в новый чат может не работать. Решение: метить как `needs_refresh=1`, при первом использовании — бот скачивает в blob storage / повторно отправляет себе в сервисный чат и обновляет `file_id`.
2. **`chat_id` / `thread_id`** в настройках — обнулять, ремапить через UI «выбрать чат-цель» после клона.
3. **Тематические настройки (Pulse-only)** при копировании в обычный ws — спросить владельца или авто-отфильтровать (модули с `theme=pulse_only` пропускаются).
4. **Транзакционность** — клон должен быть атомарным: либо всё ушло, либо ничего (одна транзакция SQLite).
5. **Размер копии** — для большого ws (много триггеров+медиа+истории) может быть медленно. Прогресс-бар.

## UX (черновик)

- **Точка входа:** на странице WorkspacePage (где «Удалить сообщество», «Сменить роль чата») — кнопка `📋 Скопировать настройки в другой чат`
- **Шаг 1:** выбор target — выпадающий список других ws владельца ИЛИ «Создать новый ws (пустой)»
- **Шаг 2:** галочки «что копируем» (по умолчанию все настройки, можно отщёлкнуть)
- **Шаг 3:** превью «что произойдёт» с предупреждениями (наложение vs замена)
- **Шаг 4:** подтверждение → прогресс-бар → готово

## API скетч

```
POST /api/workspaces/{source_id}/clone-settings-to/{target_id}
Body: {
  "include": ["module_toggles", "economy_settings", "triggers", ...],
  "overwrite": true | false,  // если в target уже есть настройки
  "theme_filter": "pulse_only_skip" | "all"
}

Response: {
  "cloned": { "module_toggles": 12, "economy_settings": 47, ... },
  "skipped": { ... },
  "warnings": [
    "47 media files need refresh on first use",
    "3 triggers had chat_id reset — выбери новые целевые чаты"
  ]
}
```

## Будущее расширение (не в MVP)

- Зависит от модулей (`module_toggles` должны быть финализированы)
- Перед Биллингом — даёт прозрачную аналитику «у этого владельца N ws» → tariff
- В Хабе — может стать карточкой «Импорт/экспорт настроек»
