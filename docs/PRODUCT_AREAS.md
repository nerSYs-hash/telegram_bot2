# C. 👤 Профиль пользователя (одна сущность — три витрины)

**Назначение:** **одна модель данных юзера, три способа её показать.** Юзер видит себя через `/profile` в боте; владелец/админ — через Метрики на сайте (расширенно); в будущем — публичная карточка.

> Архитектурное решение Ильи 24.05: страница юзера в Метриках = админская витрина #9 Профиля-паспорта, не отдельная сущность.

## Три витрины
| Витрина | Кто | Что видит |
|---|---|---|
| **Бот `/profile`** | юзер сам себя | Паспорт · Кошелёк · Активность сегодня · BBS · Достижения · Квесты · кнопки действий |
| **Сайт → Метрики → клик по юзеру** | владелец/админ | Всё то же + **админский слой**: Trust Index, наказания, граф взаимодействий, лента событий, кнопки модерации |
| **Публичная карточка (будущее)** | все | Самый узкий слой (имя, ранг, ачивки) |
