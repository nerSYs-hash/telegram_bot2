# Руководство по работе с AI-ассистентом (Jules)

Это руководство объяснит, как взаимодействовать с Jules (AI-ассистентом) и использовать возможности искусственного интеллекта в рамках проекта Pulse.

## 1. Как общаться с Jules в VS Code

Jules — это ваш персональный инженер-программист на базе ИИ, который помогает разрабатывать этот проект.

### Подключение
Для взаимодействия с Jules в VS Code используется расширение **Superpowers**.
1. Убедитесь, что расширение установлено и активно.
2. В боковой панели VS Code (обычно слева) найдите иконку чата.
3. Пишите вопросы или задачи прямо в окно чата. Jules видит весь контекст проекта и может изменять файлы, запускать тесты и помогать с архитектурой.

### Возможности
- **Написание кода**: Например, "Добавь новую команду /info в bot.py".
- **Исправление ошибок**: "Найди, почему не работает начисление рефералов".
- **Объяснение кода**: "Как работает формула майнинга в этом боте?".

## 2. AI-функции в панели управления (Admin SITE)

В веб-панели управления Pulse интегрирована модель **Gemini AI** для помощи администраторам.

- **Где найти**: Вкладка **"AI-помощник"** в боковом меню панели.
- **Что умеет**:
  - Помогает составлять тексты для триггеров.
  - Готовит тексты объявлений и рассылок.
  - Помогает анализировать ситуацию в чате.
  - Генерирует понятные описания обновлений на основе технических коммитов.

## 3. Как писать в Telegram-чат из терминала VS Code

Если вам нужно отправить сообщение в рабочий чат прямо из VS Code (например, для теста), можно использовать Telegram Bot API через терминал.

### С помощью curl
Выполните команду в терминале (подставив данные из вашего `.env` файла):

```bash
curl -s -X POST https://api.telegram.org/bot<ВАШ_BOT_TOKEN>/sendMessage \
     -d chat_id=<ВАШ_TARGET_CHAT_ID> \
     -d text="Тестовое сообщение из терминала VS Code"
```
