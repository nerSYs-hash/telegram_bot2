# БЫСТРЫЙ СТАРТ

## 🚀 Запуск за 3 шага

### Windows:

1. **Установите Python 3.10+**
   - Скачайте с https://www.python.org/downloads/
   - При установке отметьте "Add Python to PATH"

2. **Запустите установочный файл**
   - Дважды кликните `start_bot.bat`
   - Или откройте командную строку и выполните:
     ```
     start_bot.bat
     ```

3. **Готово!** Бот запущен и работает

---

### Linux / macOS:

1. **Убедитесь, что Python 3.10+ установлен**
   ```bash
   python3 --version
   ```

2. **Запустите установочный скрипт**
   ```bash
   chmod +x start_bot.sh
   ./start_bot.sh
   ```

3. **Готово!** Бот запущен и работает

---

### Альтернативный метод (все ОС):

```bash
# 1. Установите зависимости
pip install -r requirements.txt

# 2. Инициализируйте базу данных (только первый раз)
python database/db_manager.py

# 3. Запустите бота
python bot.py
```

## 🛠️ Устранение проблем

### Бот не запускается?

1. **Проверьте Python:**
   ```bash
   python --version
   # Должно быть 3.10 или выше
   ```

2. **Установите зависимости:**
   ```bash
   pip install -r requirements.txt
   ```

3. **Проверьте логи:**
   ```bash
   cat logs/bot.log
   # или в Windows:
   type logs\bot.log
   ```

### Бот запустился, но не отвечает в чате?

1. **Убедитесь, что бот добавлен в чат** с ID `-1003779843064`
2. **Дайте боту права администратора**
3. **Проверьте, что чат существует и доступен**

### Ошибка "Module not found"?

```bash
pip install python-telegram-bot python-dotenv APScheduler Jinja2 pytz
```

## 🔧 Настройки в .env

Пример `.env` (никогда не коммитим в репо!):
```env
BOT_TOKEN=<получи у @BotFather и положи СЮДА — НЕ В КОД>
MAIN_ADMIN_ID=<твой telegram id>
TARGET_CHAT_ID=<id основного чата>
INITIAL_BANK_BALANCE=10000000
INITIAL_DIFFICULTY_K=5.0
```

⚠️ `BOT_TOKEN` храним только в `.env` на сервере. Любой токен в коде/доке = угон бота за минуты.

Можно изменить:
- `INITIAL_BANK_BALANCE` - стартовый баланс банка
- `INITIAL_DIFFICULTY_K` - сложность майнинга
- `REFERRAL_REWARD` - награда за реферала
- `STATS_HOUR` - час публикации статистики (19)
- `STATS_MINUTE` - минута публикации (5)

## 💾 Резервное копирование

### Создать бэкап базы данных:

**Windows:**
```cmd
copy database\bot_database.db database\backup_%date%.db
```

**Linux/Mac:**
```bash
cp database/bot_database.db database/backup_$(date +%Y%m%d).db
```

### Восстановить из бэкапа:
```bash
# Остановите бота
# Замените файл:
cp database/backup_ДАТА.db database/bot_database.db
# Запустите бота снова
```
