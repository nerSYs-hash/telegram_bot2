💡 КАК ЭТИМ ПОЛЬЗОВАТЬСЯ?

🔹 ДЛЯ ОБЫЧНЫХ ПОЛЬЗОВАТЕЛЕЙ:

1️⃣ Откройте бота → /menu
2️⃣ Нажмите "📊 Детализация"
3️⃣ Выберите период (День/Неделя/Месяц/Год)
4️⃣ Получите Excel файл
5️⃣ Смотрите всю историю ваших Пульсов!

💰 Узнайте:
   • Сколько заработали за период
   • Куда потратили Пульсы
   • Сколько это в рублях по текущему курсу

🔹 ДЛЯ ВЛАДЕЛЬЦА:

1️⃣ Откройте бота → /menu
2️⃣ Нажмите "📊 Статистика"
3️⃣ Выберите "📊 Общая по чату"
4️⃣ Выберите период (теперь есть "Год"!)
5️⃣ Получите детальный Excel отчёт

📈 Анализируйте:
   • Динамику активности чата
   • Рост или спад по дням/месяцам
   • Вовлечённость участников
   • Эффективность системы Пульсов
