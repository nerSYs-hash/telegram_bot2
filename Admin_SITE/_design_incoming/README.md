# _design_incoming — приёмник концептов из дизайн-вкладки

Сюда складываются СЫРЫЕ концепт-артефакты (HTML/Tailwind/React),
сгенерённые Claude-визуализатором по `docs/DESIGN_BRIEF_Puls_Chat.md`.

**Это не прод-код.** Claude Code снимает отсюда разметку/токены/моушн
и пересобирает правильный компонент в `Admin_SITE/components/shared/`
под канон брифа. Файлы здесь — временный референс.

## Поток
1. Илья кидает код артефакта в чат (по одному компоненту, старт — Sidebar).
2. Claude Code сохраняет его сюда: `_design_incoming/<component>/`.
3. Ревью → сборка `shared/<Component>.jsx` → применение.
4. После вживления концепт можно удалить (или оставить для истории).

Папка в `.gitignore`-кандидаты не добавлена намеренно — пусть видно,
что в работе. Чистим по мере вживления компонентов.
