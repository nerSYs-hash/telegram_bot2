# Telegram Bot - Система Геймификации и Экономики

Комплексный Telegram-бот для управления чатом с развитой экономической моделью, статистикой и геймификацией.

## Возможности

### 💰 Экономическая система
- Внутренняя валюта "Пульсы" (💎)
- Центральный банк с начальной эмиссией 1,000,000 Пульсов
- Динамический майнинг с защитой от инфляции
- Система транзакций между пользователями
- Автоматический возврат средств при выходе из чата

### 📊 Статистика
- Детальный учет активности пользователей
- Расчет по 11 параметрам
- Ежедневная публикация топ-5 богачей в 19:05 МСК
- HTML-отчеты для владельца

### 🎰 Лотерея
- Создание лотерей с настраиваемыми параметрами
- Покупка билетов (1x, 5x, All-In)
- Автоматический розыгрыш победителей

### 👥 Реферальная система
- Уникальные реферальные ссылки
- Награды за приглашение друзей
- Система квалификации (защита от ботов)
- Отслеживание статистики

### 🔋 Социальная экономика
- Переводы между пользователями
- Система "благодарностей"
- Общественный фонд (Реактор)
- Маркетплейс услуг

### 🚪 Exit Interview
- Опрос при выходе из чата
- Аналитика причин ухода
- Уведомления администрации

## Как работает майнинг

### Формула награды:
```
Награда = K / √(Активное Ядро)
```

Где:
- **K** - коэффициент сложности (по умолчанию 5.0)
- **Активное Ядро** - количество активных пользователей за 24 часа

### Примеры:
- 5 человек: 5 / √5 ≈ 2.24 Пульса за сообщение
- 25 человек: 5 / √25 = 1.0 Пульс за сообщение
- 100 человек: 5 / √100 = 0.5 Пульса за сообщение

## Решение проблем

### Бот не запускается:

1. Проверьте правильность токена в `.env`
2. Убедитесь, что все зависимости установлены:
   ```bash
   pip install -r requirements.txt
   ```
3. Проверьте логи:
   ```bash
   cat logs/bot.log
   ```

### Бот не отвечает в чате:

1. Проверьте, что бот добавлен в целевой чат
2. Дайте боту права администратора
3. Убедитесь, что `TARGET_CHAT_ID` правильный

### Ошибки базы данных:

```bash
# Пересоздать базу
rm database/bot_database.db
python database/db_manager.py
```
