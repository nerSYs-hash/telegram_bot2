# Pulse Chat ⚡

Современный кросс-платформенный мессенджер нового поколения с геймифицированной экономикой, BBS-знакомствами, лотереей и единой панелью административного управления.

Переписан на современный реактивный стек **React 18 + TypeScript + Vite + Tailwind CSS**.

## Основные возможности

### 1. Мессенджер (Pulse Messenger)
- **Чаты и диалоги**: Личные сообщения, группы и публичные информационные каналы.
- **Интерактивные сообщения**: Цитаты и ответы, статусы отправки и прочтения (delivered / read), эмодзи-реакции (👍, ❤️, 🔥, 😂, 💎).
- **Медиа и вложения**: Отправка изображений, файлов и документов.
- **Интерактивные опросы**: Создание голосований с подсчётом голосов и процентами в реальном времени.
- **Голосовые сообщения**: Запись аудиосообщений с визуализатором волны, таймером и отменой сдвигом.
- **Звонки**: Симуляция аудио- и видеозвонков в высоком качестве с таймером длительности и управлением микрофоном/камерой.
- **Информация о диалоге**: Telegram-подобная правая панель с профилем собеседника, списком участников группы, медиа и файлами.

### 2. Внутриигровая экономика и кошелёк (Pulse Economy)
- **Баланс и активы**: Отображение баланса в Пульсах (💎), конвертация в фиат по актуальному курсу.
- **Майнинг активности**: Автоматическое накопление наград за общение и активность в беседах с возможностью мгновенного сбора.
- **Мгновенные переводы**: Безопасная отправка Пульсов контактам с комментариями.
- **График курса**: Интерактивная динамика котировок 💎 за последние 7 дней.
- **История транзакций**: Подробный журнал начислений, переводов и бонусов.

### 3. Лотерея (Pulse Lottery)
- **Джекпот**: Накопительный призовой фонд.
- **Покупка билетов**: Приобретение счастливых номеров за Пульсы.
- **Розыгрыш тиражей**: Автоматический и ручной запуск тиража с выявлением победителя.
- **История побед**: Список недавних триумфаторов с номерами билетов и суммами.

### 4. Доска знакомств и сообщество (Pulse BBS)
- **Анкеты участников**: Город, возраст, увлечения, статус верификации.
- **Фильтрация**: Сортировка по полу (Девушки / Парни) и поиск по интересам.
- **Взаимные симпатии**: Лайки анкет и быстрый переход к диалогу в один клик.

### 5. Реферальная программа
- **Персональные ссылки**: Генерация уникальных инвайт-ссылок.
- **Вознаграждения**: Начисление бонусов за каждого зарегистрированного друга.

### 6. Панель управления (Admin Console)
- **Мульти-арендность (Workspaces)**: Переключение между пространствами и привязанными Telegram-ботами.
- **Хаб модулей**: Мгновенное включение и отключение модулей (Экономика, Лотерея, BBS, Звонки, Пресс-релизы, Модерация).
- **Настройка экономики**: Корректировка скорости майнинга, процента отчислений в джекпот и ежедневных бонусов.
- **Аналитика и метрики**: Суточный график сообщений, оборота валюты и аптайма.
- **Пресс-релизы**: Редактор и публикация официальных системных новостей.
- **Диагностика**: Очистка кэша и дефрагментация.

## Запуск проекта

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера (порт 3000)
npm run dev

# Сборка проекта
npm run build

# Проверка типов
npm run lint
```
