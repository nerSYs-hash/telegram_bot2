## 1. Блок-схема обработки сообщения

```
┌─────────────────────────────────────────────────────────────────┐
│                 СООБЩЕНИЕ ПОПАЛО В ЧАТ                          │
└──────────────────────────┬──────────────────────────────────────┘
                           │
                           ▼
               ┌───────────────────────┐
               │ Есть включённые       │──нет──▶ ВЫХОД (ничего)
               │ триггеры?             │
               └──────────┬────────────┘
                          │да
                          ▼
               ┌───────────────────────┐
               │  Перебираем триггеры  │
               │  один за другим       │
               └──────────┬────────────┘
                          │
                          ▼
         ═══════════════════════════════════════
         ║    ФИЛЬТР 1: ГДЕ сработать?         ║
         ║    where_fires: "all" / [thread_id] ║
         ═══════════════════════════════════════
                          │
                     ┌────┴────┐
                     │ подходит│──нет──▶ след. триггер
                     └────┬────┘
                          │да
                          ▼
         ═══════════════════════════════════════
         ║    ФИЛЬТР 2: КТО написал?           ║
         ║  all / users / owner / admins_owner ║
         ═══════════════════════════════════════
                          │
                     ┌────┴────┐
                     │ подходит│──нет──▶ след. триггер
                     └────┬────┘
                          │да
                          ▼
         ═══════════════════════════════════════
         ║   ФИЛЬТР 3: ВЕРОЯТНОСТЬ             ║
         ║   rand(1-100) > probability?        ║
         ═══════════════════════════════════════
                          │
                     ┌────┴────┐
                     │ прошёл  │──нет──▶ след. триггер
                     └────┬────┘
                          │да
                          ▼
         ═══════════════════════════════════════
         ║   ФИЛЬТР 4: СОВПАДЕНИЕ ТЕКСТА       ║
         ║   condition:                        ║
         ║     • exact (точное)                ║
         ║     • contains (содержит)           ║
         ║     • starts_with (начинается с)    ║
         ║     • ends_with (заканчивается на)  ║
         ║     • whole_word (целое слово)      ║
         ║   по списку keywords                ║
         ═══════════════════════════════════════
                          │
                     ┌────┴────┐
                     │совпало? │──нет──▶ след. триггер
                     └────┬────┘
                          │да
                          ▼
         ═══════════════════════════════════════
         ║   ФИЛЬТР 5: ЛИМИТ СРАБАТЫВАНИЙ      ║
         ║   fire_count >= fire_limit ?        ║
         ═══════════════════════════════════════
                          │
                     ┌────┴────┐
                     │ есть?   │──да──▶ след. триггер
                     └────┬────┘
                          │нет
                          ▼
         ╔═══════════════════════════════════════╗
         ║   🎯 ТРИГГЕР СРАБОТАЛ                 ║
         ║   Записываем в журнал                 ║
         ╚═══════════════════════════════════════╝
                          │
                          ▼
         ┌─────────────────────────────────────┐
         │  ВЫПОЛНЯЕМ ВСЕ ACTIONS (мульти!)    │
         │  каждое со своими настройками       │
         └──────┬──────────────────────────────┘
                │
                ├──▶ 💬 msg_chat     (ответ в чат — можно РОТАЦИЮ: текст 1/2/3)
                │         └─ reply_target: none / initiator / quoted
                │         └─ кнопки-ссылки
                │         └─ удалять ответ бота через N сек / после след. триг.
                │
                ├──▶ ✉️ msg_dm        (ответ в ЛС таргету)
                │
                ├──▶ 📌 pin          (закрепить сообщение юзера)
                │
                ├──▶ 🗑 delete       (удалить: само сообщение / цитируемое)
                │
                ├──▶ 🔇 mute         (замутить на duration)
                │         └─ target: initiator / specific user / никого
                │
                ├──▶ ⚠️ warn         (варн с эскалацией:
                │                    1-й — предупр., 3-й — мут 1ч,
                │                    5-й — мут 24ч и т.д.)
                │         └─ warn_period: за какой период считать
                │
                └──▶ 😀 emoji       (поставить реакцию на сообщение)
                          │
                          ▼
         ┌─────────────────────────────────────┐
         │  fire_count += 1                    │
         │  Если auto_pin — закрепляем         │
         │   ответное сообщение бота           │
         └──────────────┬──────────────────────┘
                        │
                        ▼
         ┌─────────────────────────────────────┐
         │  Было "delete"? ──▶ STOP (break)    │
         │  Иначе ──▶ след. триггер            │
         └─────────────────────────────────────┘
```

## 2. Таблица всех полей триггера

| Поле | Что означает | Возможные значения |
|------|-------------|-------------------|
| `name` | Название триггера | любой текст |
| `keywords` | Ключевые слова | список через запятую |
| `condition` | Тип поиска | `exact` / `contains` / `starts_with` / `ends_with` / `whole_word` |
| `probability` | Шанс срабатывания, % | 0 – 100 |
| `where_fires` | Где работает | `all` или список thread_id (веток чата) |
| `initiator` | Кто триггерит | `all` / `users` / `owner` / `admins_owner` |
| `target` | На кого действует | `initiator` / `specific` (юзер по ID) / `nobody` |
| `actions` | Действия (**МУЛЬТИ**) | `msg_chat`, `msg_dm`, `pin`, `delete`, `mute`, `warn`, `emoji` |
| `action_configs` | Настройки действий | JSON со спец-полями для каждого экшена |
| `fire_limit` | Лимит срабатываний | число или `null` (без лимита) |
| `fire_count` | Сработал раз | считается автоматически |
| `warn_period` | Период подсчёта варнов | секунды |
| `auto_pin` | Автозакреп ответа бота | 0 / 1 |
| `enabled` | Включён? | 0 / 1 |

---

## 3. Типы поиска (condition)

| Ключ | Русское название | Пример для `ключ = "куку"` |
|------|-----------------|---------------------------|
| `exact` | Точное совпадение | сработает только на `куку` |
| `contains` | Содержит подстроку | сработает на `я куку написал` |
| `starts_with` | Начинается с | сработает на `куку весь день` |
| `ends_with` | Заканчивается на | сработает на `привет куку` |
| `whole_word` | Целое слово | сработает на `куку всем!`, но НЕ на `кукуруза` |

## 4. Действия (actions) и их настройки

### 💬 msg_chat — ответ в чат
- `text` — текст (поддерживает HTML и плейсхолдеры `%act_X%`, `%rpl_X%`)
- `reply_target` — куда привязать ответ:
  - `none` — обычное сообщение
  - `initiator` — реплай на сообщение написавшего
  - `quoted` — реплай на цитируемое сообщение
- `buttons` — список кнопок-ссылок `[{text, url}]`
- **РОТАЦИЯ** — можно указать несколько вариантов текста, бот выбирает случайно или по кругу
- Удаление ответа бота: через N секунд / после следующего срабатывания

### ✉️ msg_dm — ответ в личку
- `text` — текст для ЛС
- Получатель определяется полем `target`

### 📌 pin — закрепить
- Закрепляет само сообщение пользователя
- `notify` — уведомлять участников чата о закрепе

### 🗑 delete — удалить
- `what` — что удалять: `trigger_word` (само сообщение) / `quoted_message` (цитируемое)

### 🔇 mute — мут
- `duration` — `5m` / `30m` / `1h` / `24h` / `forever` и т.д.
- Применяется к `target`

### ⚠️ warn — предупреждение с эскалацией
- Считает количество варнов юзера за `warn_period`
- Пороги эскалации (WARN_ESCALATION в коде):
  - 3 варна → мут 1 час
  - 5 варнов → мут 24 часа
  - дальше больше
- Применяется к `target`

### 😀 emoji — реакция
- `emoji` — символ реакции (`👀`, `🔥`, `❤️` и т.д.)

## 5. Что есть в боте, но НЕТ на сайте сейчас

| Возможность бота | Есть на сайте? |
|-----------------|---------------|
| Мульти-экшены (ответить + замутить + варн одновременно) | ❌ один action на выбор |
| Ротация текстов ответа (1/2/3 варианта) | ❌ |
| `reply_target` (отвечать на своё / на цитируемое) | ❌ |
| Кнопки-ссылки в ответе | ❌ |
| Закреп сообщения юзера (pin) | ❌ |
| Удаление цитируемого сообщения | ❌ |
| Эмодзи-реакции | ❌ |
| Варны с эскалацией и настройкой порогов | ⚠️ кнопка есть, настроек нет |
| Автозакреп ответа бота | ❌ |
| Лимит срабатываний | ❌ |
| Фильтр по веткам (`where_fires`) | ⚠️ только `chat/pv/global`, не конкретные ветки |
| `target` (на кого действует) | ❌ |
| Плейсхолдеры `%act_X%`, `%rpl_X%`, `%act_form%` | ❌ нет подсказок |
| Кнопки Play/Pause (остановить без удаления) | ❌ |
| Копирование триггера | ❌ |
| Загрузка медиа (фото/видео/гиф) | ❌ |

## 6. Предложение: новый мастер триггера

Переделать мастер из **4 шагов → 6 шагов** — каждый шаг = один фильтр/блок из схемы:

```
ШАГ 1: ЧТО ЛОВИМ
  └─ название, ключевые слова, тип поиска

ШАГ 2: ГДЕ И КОГДА
  └─ конкретные ветки чата, вероятность, лимит срабатываний

ШАГ 3: КТО И НА КОГО
  └─ инициатор (кто пишет) + target (на кого действие)

ШАГ 4: ЧТО ДЕЛАЕМ
  └─ МУЛЬТИ-ВЫБОР экшенов (чекбоксы, не радио!)

ШАГ 5: НАСТРОЙКИ ЭКШЕНОВ
  └─ разворачиваются только выбранные на шаге 4
  └─ плейсхолдеры, медиа (фото/видео/гиф), кнопки

ШАГ 6: ПРЕВЬЮ + СОХРАНИТЬ
```

### Дополнительные функции в списке триггеров:
- 🟢 Кнопка Play/Pause (пауза без удаления)
- 📋 Копировать триггер (берёт все настройки, даёшь новое имя/слова)
- ✏️ Редактирование подгружает все поля в форму (сейчас поле текста пустое)
