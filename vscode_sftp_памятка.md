# VS Code + SFTP + Git — Памятка

---

## Где что происходит

| Действие | Что делает | Горячая клавиша |
|----------|-----------|-----------------|
| **Ctrl + S** | Сохраняет файл **на вашем ПК** | `Ctrl + S` |
| **Stage (+)** | Отмечает файл для коммита | Кнопка **+** в Source Control |
| **Commit** | Фиксирует «снимок» изменений в Git | Галочка ✓ в Source Control |
| **SFTP: Upload** | Отправляет файл **на сервер** | ПКМ → SFTP: Upload File |

---

## Пошаговый процесс

### 1. Сохранение файла

- Отредактировали файл → на вкладке появилась **белая точка** (●)
- Нажали `Ctrl + S` → точка исчезла → файл сохранён **на вашем ПК**
- На сервер файл **НЕ попал** — только на диск

### 2. Где найти изменённые файлы

- Левая панель → иконка **Source Control** (ветвящаяся линия) или `Ctrl + Shift + G`
- Там список **всех файлов**, которые изменились с последнего коммита
- Это ваш «пул изменённых файлов»

### 3. Коммит — фиксация изменений в Git

Допустим, вы работаете над двумя фичами одновременно:

- **Фича A** — готова (3 файла изменены)
- **Фича B** — ещё в работе (2 файла изменены)

Что делать:

1. В Source Control наведите на файл **фичи A** → нажмите **+** (Stage Changes)
2. Повторите для всех файлов фичи A
3. Напишите сообщение коммита, например: `Добавил систему баланса`
4. Нажмите **Commit** (галочка ✓)

Результат: фича A зафиксирована. Файлы фичи B остались в списке — их закоммитите потом.

### 4. Загрузка на сервер (SFTP)

Заливаете **только готовые файлы**:

| Способ | Как сделать |
|--------|------------|
| **Один файл** | ПКМ по файлу в проводнике → `SFTP: Upload File` |
| **Активный файл** | `Ctrl + Shift + P` → `SFTP: Upload Active File` |
| **Папка целиком** | ПКМ по папке → `SFTP: Upload Folder` |
| **Весь проект** | `Ctrl + Shift + P` → `SFTP: Sync Local → Remote` |

> ⚠️ **Не используйте Sync**, если часть файлов ещё не готова — он зальёт всё!

## Быстрая формула

```
Ctrl+S  →  Source Control (+)  →  Commit  →  ПКМ → SFTP: Upload
сохранил    выбрал файлы        зафиксировал   отправил на сервер
```

## Частые ситуации

### «Я изменил файл, но не хочу заливать его на сервер»

Просто не делайте Upload. Файл останется только на вашем ПК. Можете закоммитить его в Git для сохранности, но на сервер он не попадёт, пока вы сами не сделаете Upload.

### «Я случайно залил не тот файл»

Откатите файл на сервере: ПКМ по файлу → `SFTP: Diff with Remote` (посмотреть разницу). Если нужно вернуть старую версию — загрузите её с сервера: `SFTP: Download File`.

### «Хочу скачать файлы с сервера к себе»

ПКМ по файлу или папке → `SFTP: Download File / Folder`

### «Хочу видеть разницу между моим файлом и серверным»

ПКМ по файлу → `SFTP: Diff with Remote`

## Настройки sftp.json

```json
{
    "name": "Pulse Bot Server",
    "host": "37.230.114.168",
    "protocol": "sftp",
    "port": 22,
    "username": "root",
    "password": "ваш_пароль",
    "remotePath": "/root/economybot",
    "uploadOnSave": false
}
```

- `uploadOnSave: false` — файлы **не заливаются автоматически** при Ctrl+S (рекомендуется)
- `uploadOnSave: true` — каждый Ctrl+S сразу отправляет файл на сервер (удобно, но опасно)
