# Руководство пользователя - Pulse 4ever Bot

## 🎯 Быстрый старт

### 1. Запуск бота

```bash
cd C:\pulse_bot
python fix_imports.py  # Первый раз
python run.py          # Запуск бота
```

### 2. Первоначальная настройка

#### Шаг 1: Установить основной чат

1. Добавьте бота в ваш группо чат
2. Сделайте его администратором
3. В чате выполните команду: `/set_chat`

✅ Бот сохранит ID чата и сможет генерировать пригласительные ссылки

#### Шаг 2: Подключить журнал событий

1. Создайте канал для журнала
2. Добавьте бота как администратора (права: отправка и удаление сообщений)
3. Откройте бота в личных сообщениях
4. Выполните `/owner_panel` → [Настроить журнал]
5. Получите код и перешлите его в канал

✅ Журнал подключен, все события будут логироваться

## 👥 Для обычных пользователей

### Регистрация в чате

1. Откройте бота @Pulse_4ever_Bot

### Что дальше?

- Дождитесь уведомления от бота
- При одобрении получите личную ссылку-приглашение

## 👨‍💼 Для администраторов

### Команды

```
/admin_panel - Открыть панель администратора
```

### Обработка заявок

1. Откройте `/admin_panel`
2. Нажмите [Новые заявки]
3. Изучите анкету пользователя
4. Выберите действие:

#### Одобрить заявку:
- Нажмите [Одобрить]
- Бот сгенерирует одноразовую ссылку
- Пользователь получит уведомление

#### Отклонить заявку:
- Нажмите [Отклонить]
- Укажите причину отклонения
- Пользователь получит уведомление и сможет подать заявку снова

### Важно знать:

- ⏰ Заявка блокируется на **2 минуты** при открытии
- 🔒 Другие админы не видят заблокированные заявки
- ⏱️ Если не обработать за 2 минуты - заявка снова становится доступной
- 📢 Владелец видит все ваши действия

## 👑 Для владельца

### Команды

```
/owner_panel - Открыть панель владельца
/set_chat - Установить основной чат (выполнять в чате)
```

### Панель управления

#### [Новые заявки]
- Работает так же как у администраторов
- Видны все заявки

#### [Админы]
- **[Добавить]** - добавить администратора по ID
- **[Удалить]** - удалить администратора
- Список всех администраторов

#### [Черный список]
- **[Добавить]** - заблокировать пользователя
  - Укажите ID или @username
  - Укажите причину блокировки
- **[Удалить]** - разблокировать пользователя

#### [Проверка]
- Проверить любого пользователя по:
  - Telegram ID
  - @username
  - #userXXX
- Узнать:
  - Заполнял ли анкету
  - Состоит ли в чате
  - Контактные данные

#### [Настроить журнал]
1. Создайте канал
2. Добавьте бота как администратора
3. Получите код от бота
4. Перешлите код в канал
5. Готово!

## 📊 Журнал событий

### Что логируется:

| Событие | Хештег | Описание |
|---------|--------|----------|
| Новая заявка | #Новая_заявка | Пользователь подал заявку |
| Одобрение | #Одобрено | Заявка одобрена админом |
| Отказ | #Отказ | Заявка отклонена |
| Вход | #Вход | Пользователь вступил в чат |
| Выход | #Выход | Пользователь вышел |
| Исключен | #Исключен | Кикнут администратором |
| Профиль | #Профиль | Изменение username/имени |
| Фото | #Фото | Смена аватара |
| Активность | #Активность | Неактивен 60+ дней |
| Блокировка | #Блокировка | Добавлен в ЧС |
| Разблокировка | #Разблокировка | Удален из ЧС |

### Статусы:
- **#Новый** - впервые вступает
- **#Возвращение** - был в чате ранее

### Кнопки:
- **[Написать в ЛС]** - для связи с пользователем

## 🔄 Автоматические процессы

### Проверка активности
- **Каждые 24 часа**
- Проверяет пользователей неактивных 60+ дней
- Логирует в журнал

### Очистка фото
- **Каждые 24 часа**
- Удаляет фото старше 14 дней из журнала
- Экономит место

### Очистка блокировок
- **Каждые 2 минуты**
- Разблокирует заявки если прошло 2 минуты
- Делает их доступными для других админов

## 🆘 Частые вопросы

### Q: Заявка не появляется у админов?
**A:** Проверьте что:
1. Пользователь заполнил анкету полностью
2. Пользователь не в черном списке
3. Заявка не обрабатывается другим админом

### Q: Не генерируются ссылки?
**A:** Выполните `/set_chat` внутри группового чата

### Q: Журнал не работает?
**A:** Проверьте что:
1. Бот добавлен в канал
2. Бот - администратор канала
3. У бота есть права на отправку и удаление сообщений

### Q: Пользователь не получил уведомление?
**A:** Проверьте что:
1. Пользователь не заблокировал бота
2. Бот имеет права отправлять сообщения
